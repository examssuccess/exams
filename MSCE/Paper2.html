Instructions
(1.) This paper contains 19 printed pages. Please check.
(2.) Write your Examination Number at the top of each page of this question paper in the spaces provided.
(3.) Answer all the six questions in Section A and any four questions from Section B.
(4.) The maximum number of marks for each answer is indicated against each question.
(5.) Scientific calculators may be used.
(6.) The blank answer sheet at the end of the question paper can be used if required.

(1.) (a.) Rational Expressions: Simplify $\dfrac{3b}{y + b} + \dfrac{2b}{y - b} - \dfrac{6b^2}{b^2 - y^2}$

(b.) Mensuration: Given that the area of a room is 66 m², calculate the width (x) of the room if the length is 5 m more than the width.


$ (a.) \\[3ex] \dfrac{3b}{y + b} + \dfrac{2b}{y - b} - \dfrac{6b^2}{b^2 - y^2} \\[5ex] \underline{\text{Denominators}} \\[3ex] b^2 - y^2 = (b + y)(b - y) \quad[\text{Difference of Two Squares}] \\[3ex] y + b = b + y \quad[\text{Commutative Property}] \\[3ex] y - b = -b + y = -(b - y) \quad[\text{Distributive Property}] \\[3ex] \implies \\[3ex] \dfrac{3b}{b + y} + \dfrac{2b}{-(b - y)} - \dfrac{6b^2}{(b + y)(b - y)} \\[5ex] = \dfrac{3b(b - y) - 2b(b + y) - 6b^2}{(b + y)(b - y)} \\[5ex] = \dfrac{-5b^2 - 5by}{(b + y)(b - y)} \\[5ex] = \dfrac{-5b(b + y)}{(b + y)(b - y)} \\[5ex] = -\dfrac{5b}{b - y} \\[5ex] (b.) \\[3ex] \text{width} = x\;m \\[3ex] \text{length} = (x + 5)\;m \\[3ex] \text{Area} = \text{width} \times \text{length} = 66\;m^2 \\[3ex] x(x + 5) = 66 \\[3ex] x^2 + 5x = 66 \\[3ex] x^2 + 5x - 66 = 0 \\[3ex] (x + 11)(x - 6) = 0 \\[3ex] x + 11 = 0 \text{ or } x - 6 = 0 \\[3ex] x = -11 \text{ or } x = 6 \\[3ex] x = 6\;m \quad[\text{The width cannot be negative}] $
(2.) (a.) Radical Expressions: Without using a calculator, rationalise the denominator of $\dfrac{\sqrt{2} - \sqrt{5}}{\sqrt{2} + \sqrt{5}} \\[5ex]$ (b.) Polynomials: Given that $(x - 1)$ and $(x - 2)$ are factors of the polynomial $ax^3 + bx^2 + 12x - 4$, find the values of $a$ and $b$.


$ \dfrac{\sqrt{2} - \sqrt{5}}{\sqrt{2} + \sqrt{5}} \\[5ex] ............................................... \\[3ex] \text{Conjugate of } \sqrt{2} + \sqrt{5} = \sqrt{2} - \sqrt{5} \\[3ex] ............................................... \\[3ex] = \dfrac{\sqrt{2} - \sqrt{5}}{\sqrt{2} + \sqrt{5}} \times \dfrac{\sqrt{2} - \sqrt{5}}{\sqrt{2} - \sqrt{5}} \\[5ex] ............................................... \\[3ex] (\sqrt{2} - \sqrt{5})(\sqrt{2} - \sqrt{5}) \\[3ex] = 2 - \sqrt{10} - \sqrt{10} + 5 \\[3ex] = 7 - 2\sqrt{10} \\[5ex] (\sqrt{2} + \sqrt{5})(\sqrt{2} - \sqrt{5}) \\[3ex] = (\sqrt{2})^2 - (\sqrt{5})^2 \quad[\text{Difference of Two Squares}] \\[3ex] = 2 - 5 \\[3ex] = -3 \\[3ex] ............................................... \\[3ex] = -\dfrac{(7 - 2\sqrt{10})}{3} \\[5ex] (b.) \\[3ex] \text{Factor: } x - 1 \\[3ex] \text{Zero: } x - 1 = 0 \\[3ex] x = 1 \\[5ex] \text{Factor: } x - 2 \\[3ex] \text{Zero: } x - 2 = 0 \\[3ex] x = 2 \\[5ex] \underline{\text{Factor Theorem}} \\[3ex] ax^3 + bx^2 + 12x - 4 \\[3ex] \text{For } x = 1 \\[3ex] a(1)^3 + b(1)^2 + 12(1) - 4 = 0 \\[3ex] a(1) + b(1) + 12 - 4 = 0 \\[3ex] a + b + 8 = 0 \\[3ex] a + b = -8 \quad ...eqn.(1) \\[5ex] \text{For } x = 2 \\[3ex] a(2)^3 + b(2)^2 + 12(2) - 4 = 0 \\[3ex] a(8) + b(4) + 24 - 4 = 0 \\[3ex] 8a + 4b + 20 = 0 \\[3ex] 8a + 4b = -20 \quad ...eqn.(2) \\[5ex] 8 \times eqn.(1) \implies \\[3ex] 8a + 8b = -64 \quad ...eqn.(3) \\[5ex] eqn.(3) - eqn.(2) \implies \\[3ex] 4b = -44 \\[3ex] b = -\dfrac{44}{4} \\[5ex] b = -11 \\[5ex] \text{Substitute for $b$ in } eqn.(1) \\[3ex] a + (-11) = -8 \\[3ex] a - 11 = -8 \\[3ex] a = -8 + 11 \\[3ex] a = 3 $
(3.) (a.) Set Theory: Given that P, Q and R are three intersecting sets, draw and shade the region defined by $P' \cap Q \cap R$.

(b.) Applications of Arithmetic Sequences: Meria started a business of selling maize and sold 80 bags during the first month.
If she decided to increase her sales by 20 bags every month, calculate the number of bags of maize that were sold in the 12th month of her business.


Let us begin with a working copy


$ \mu = \{1, 2, 3, 4, 5, 6, 7, 8\} \\[5ex] P = \{1, 2, 4, 5\} \\[3ex] P' = \{3, 6, 7, 8\} \\[5ex] Q = \{2, 3, 5, 6\} \\[5ex] R = \{4, 5, 6, 7\} \\[5ex] P' \cap Q = \{3, 6\} \\[3ex] P' \cap Q \cap R = \{6\} \\[3ex] $ (a.) The region defined by $P' \cap Q \cap R$ is shaded as shown



$ (b.) \\[3ex] \underline{\text{Arithmetic Sequence}} \\[3ex] \text{1st month} = \text{1st term, } a = 80 \\[3ex] \text{common difference, } d = 20 \quad[\text{20 bags every month}] \\[3ex] \text{2nd month} = \text{2nd term} = a + d = 80 + 20 = 100 \\[3ex] \text{3rd month} = \text{3rd term} = a + 2d = 80 + 2(20) = 80 + 40 = 120 \\[3ex] \text{4th month} = \text{4th term} = a + 3d = 80 + 3(20) = 80 + 60 = 140 \\[3ex] \text{12th month} = \text{12th term} = a + 11d = 80 + 11(20) = 80 + 220 = 300 \\[3ex] $ If she decided to increase her sales by 20 bags every month, 300 bags of maize were sold in the 12th month of her business.
(4.) (a.) Mensuration: Calculate the radius of a sphere whose volume is 440 cm³, giving the answer to one decimal place. (Take π = $\dfrac{22}{7}$).

(b.) Locus and Construction: Using a pair of compasses and a ruler only, construct in the same diagram:
  • a circle centre O of radius 3 cm
  • a point R outside the circle and 7 cm from the centre O
  • a tangent PR at P
  • a perpendicular bisector of PR intersecting OR at B.

$ (a.) \\[3ex] \underline{\text{Sphere}} \\[3ex] V = \dfrac{4}{3}\pi r^3 \\[5ex] \text{where} \\[3ex] V = \text{volume} = 440\;cm^3 \\[3ex] r = \text{radius} = ? \\[3ex] \pi = \dfrac{22}{7} \\[5ex] \dfrac{4\pi r^3}{3} = 440 \\[5ex] r^3 = 440 \times \dfrac{3}{4\pi} \\[5ex] = 440 \times \dfrac{3}{4} \times \dfrac{7}{22} \\[5ex] = 5 \times 3 \times 7 \\[3ex] = 105 \\[3ex] r = \sqrt[3]{105} \\[3ex] = 4.71769398 \\[3ex] \approx 4.7\;cm \quad[\text{to one decimal place}] \\[3ex] $ (b.) The steps in the construction are:
• A circle centre O of radius 3 cm
(1.) Mark a point, O
(2.) Measure a length of 3 cm on the ruler with the compass.
(3.) With the centre at O, draw a circle.
That measured length of 3 cm becomes the radius of the circle.

• A point R outside the circle and 7 cm from the centre O
(4.) Using the ruler, draw a straight line from O measuring a length of 7 cm.
(5.) Mark the endpoint, R
This implies that $|OR| = 7\;cm$

• A tangent PR at P
The tangent to the circle is perpendicular to the radius at the point of contact
This implies that:
The point of contact should be point P
$\overline{PR}$ should be the tangent to the circle
$\overline{OP}$ should be the radius
$\overline{OR}$ should be the diameter of a new circle
So, $\overline{OP} \perp \overline{PR}$
To begin, we need to contruct the midpoint of $\overline{OR}$

(6.) Open the compass to a length greater than half the length $\overline{OR}$;

$ \dfrac{1}{2} \times |OR| \\[5ex] = \dfrac{1}{2} \times 7 \\[5ex] = 3.5\;cm \\[3ex] $ Any length greater than 3.5 cm (and preferably less than 7 cm) is fine.
For example, we can use a length of 5 cm.

(7.) From point O, draw arcs above and below $\overline{OR}$
(8.) Using the same length, from point, R, draw arcs above and below $\overline{OR}$ that intersect the previous arcs you just drew
(9.) Join the arc intersections to draw the line that bisects $\overline{OR}$ at the midpoint, say M1
(10.) With the centre, M and radius, $|OM|$, draw a second circle.

Label any intersection point as P

• A perpendicular bisector of PR intersecting OR at B

(b.) Circle Theorems: Figure 1 shows a circle ABD with centre O and a tangent CDE at D.



If angle ADE = x° and angle BCD = 90°, show that angle DBC = angle ABD.


$ (b.) \\[3ex] \underline{\text{Figure 1}} \\[3ex] \angle ABD = \angle ADE = x \quad \text{$\angle$ between tangent $\overline{ED}$ and chord $\overline{AD}$ = $\angle$ in alternate segment} \\[3ex] \angle ADB = 90^\circ \quad\text{$\angle$ in a semicircle} \\[3ex] \angle ABC = 90^\circ \quad \text{radius $\overline{OB}$ is $\perp$ to tangent $\overline{CB}$ at point of contact} \\[5ex] \angle ABC = \angle ABD + \angle DBC \quad[\text{Diagram}] \\[3ex] 90 = x + \angle DBC \\[3ex] \angle DBC = 90 - x \\[5ex] \angle ADE + \angle ADB + \angle BDC = 180^\circ \quad\text{sum of $\angle s$ on a straight line} \\[3ex] x + 90 + \angle BDC = 180 \\[3ex] \angle BDC = 180 - x - 90 \\[3ex] \angle BDC = 90 - x \\[5ex] \underline{\triangle BDC} \\[3ex] \angle DBC + \angle BDC + \angle BCD = 180^\circ \quad\text{sum of $\angle s$ in a triangle} \\[3ex] 90 - x + 90 - x + 90 = 180 \\[3ex] 270 - 2x = 180 \\[3ex] 270 - 180 = 2x \\[3ex] 2x = 90 \\[3ex] x = \dfrac{90}{2} \\[5ex] \angle ABD = x = 45^\circ \\[5ex] \angle DBC = 90 - x \\[3ex] = 90 - 45 \\[3ex] = 45^\circ \\[5ex] \therefore \angle ABD = \angle DBC = 45^\circ $
